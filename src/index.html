What is not shared

The doorway is the only common thing. Everything behind each door stays there.

Backends

Each room runs its own FastAPI process on its own port, from 8001 to 8010. Atrium does not proxy them.

Databases

Every repo keeps its own SQLite file. The build copies only the frontend's dist/ tree; no database or .env enters the site.

Memory

No combined search index, no cross-app cookies, no shared progress store. Only one app saves a key in local storage, under its own name.
